# Crooked Pantry

> Crooked Pantry: ai app controlled by shaking your phone.

A one-month ai project called Crooked Pantry — controlled by shaking your phone. Built fast, shipped faster.

## Features
- Core ai loop that works in under 10 seconds of use
- The twist: controlled by shaking your phone
- Zero-setup onboarding — useful within one minute
- Share/export so friends can join or compete

## Stack
- Qwen + Hono
- SQLite
- TypeScript

## Getting started
```
npm install && npm run dev
```
